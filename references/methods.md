# 方法导航：把原方法变成具体搜集任务

这是对 Wiki 的应用整理。每条指向完整方法，下面的研究动作不是原作者逐字表述。导航覆盖已选入的相关方法，不宣称穷尽知识库。采用前回读原条目；相似名称不代表同一种操作。

## 从受众和角度产生问题

完整入口：`methods/playbook/playbook-topic-divergence`；该页明确区分以下五种方法。

| 原方法 | 用于搜集时的动作 | 所需材料与边界 |
|---|---|---|
| 需求与受众立场 | 写具体人群在什么场景里卡在哪里；分别探索被理解、解决麻烦、获得答案 | 评论/访谈/用户经历中的处境和原话；无调查时标受众假设，不能声称所有人都这样 |
| 认知反差 | 找预期由何而来，再找与之不同的观察；核对比较条件 | 两端真实材料；不能把反常当已证明的因果，也不预先编反转 |
| 人物关系 | 分别找各方的目标、限制、选择、受影响方式；用原话或行动承载 | 不只收谁支持谁反对；没有行为证据不猜恶意、不制造对立 |
| 换视角与立场 | 拆开事实与原作者态度，再从使用者、执行者、受影响者的问题检索 | 每个方向对应具体材料；反向观点只是候选，同一结论换词不是新角度 |
| 可感知的实用价值 | 将麻烦缩到一个具体任务，寻找可展示的动作、步骤与限制 | 拟议实验可以成为方向，但尚未执行要明说；不承诺时间/收益 |

想判断共鸣、利益和好奇的原理与变体时，沿该页读取 `sources/community/zsxq-14422154145122452`。需要认知反差/关系的原始讨论，读 `sources/community/zsxq-55522415444181484`；换视角读 `sources/community/zsxq-55522822524542824`。只选当前需要的部分，不批量读例文，不沿用原文夸大、攻击性或个案泛化规则。

## 给判断找材料

| 完整条目 | 独立操作，不能被“找证据”替代 | 要采集到的颗粒度 |

| `concepts/body_expression#13` 观点要有论据 | 为一个看法找不同维度的理由；尝试正反两件真事 | 每件事的来龙去脉与能支持的部分；不够就保留一件，不凑数 |
| `concepts/body_expression#14` 数字说具体 | 将大数拆成可复算的小数，保留对象、单位、周期、基准 | 原表/原报告位置、分项与计算式、估算假设；不混淆收入/利润、招聘/录用 |
| `concepts/body_expression#17` 说清成立条件 | 主动寻找适用与不适用情形，检查外推范围 | 样本、任务、版本、时点、前提；个案不升级成人群规律 |
| `concepts/body_expression#19` 分清事实、推测和转述 | 分离观察、来源自述、作者判断、自己的推断和待核信息 | 每个关键判断的来源链，说明当前读到原文还是转载/摘要 |
| `concepts/body_expression#20` 先说反对声音 | 找真实而有力的反对理由，准确复述后研究回应 | 对方主张的原上下文，支持证据、反证与未解决分歧；不编稻草人 |
| `concepts/body_expression#39` 做对比 | 选择同一个比较维度；以前/现在、预期/结果等分别采集 | 真实两端、条件是否一致、变化与其他可能原因；不是只挑落差最大的数 |
| `rules/intelligence/intelligence-rule-creator-increment` 创作者增量 | 选择实测、对照、解释机制、还原过程、核验承诺或选择框架中的适当动作 | 指明相对原资讯新增的答案/证据；没有材料就保留为待研究问题 |
| `rules/intelligence/intelligence-rule-thin-evidence` 事实材料偏薄 | 检查是否只有标题或口号，优先追正文与原始出处 | 资讯准入判断，不能拿它压制有潜力但待采访/实测的探索方向 |

## 找到值得讲的细节

| 完整条目 | 搜集动作 | 容易丢失的区别 |
|---|---|---|
| `concepts/body_expression#16` 原话直接放进来 | 记录说话者、场景、原句、上下文、时间点、可公开范围 | 当事人原话与作者转述不同；没采访过不伪造对话 |
| `concepts/body_expression#24` 用观众的原话 | 在评论、问答或真实交流里找具体困惑、吐槽和追问 | 真实说出口的话，不等于对方心里未表达的感受；评论自述仍需核实 |
| `concepts/body_expression#23` 替观众说出心里话 | 根据实际处境探索两难、委屈和需求，必要时访谈求证 | 属于解释性假设，不能冒充观众逐字原话，不凭空制造焦虑 |
| `concepts/body_expression#22` 抽象词换成画面 | 追问感受由哪个动作、物件、感官细节或数字产生 | 直接采集真实场景，不把写作想象补成发生过的细节 |
| `concepts/body_expression#41` 说具体的人和事 | 交代人物、地点、时间、配角行动与事件过程 | 信息具体还要让陌生读者理解；多细节不等于主线清楚 |
| `concepts/body_expression#10` 做法说到能照做 | 准备、实际动作、用量/次数、原因、观察到的结果分别采集 | 官方步骤、自述效果与自己实测分开；未知用量不补写 |

## 用内容形式反查素材缺口

先读 `concepts/structure_quick`。这些是候选素材要求，不能为了套结构捏造阶段或提前改用户角度。

- `concepts/structure#16` **算一笔账**：需要能逐项展开的真实数字。补收入、支出、时间和比较基准；没有明细就不能交伪精确账本。
- `concepts/structure#30` **折腾经历**：需要完整起因、中间失败尝试/补救、转折与现状。只有坏结果不足以讲反复试错；允许没有圆满结局。
- `concepts/structure#13` **观点＋一反一正两个例子**：需要两件可比较的真事。例子为观点服务，与追求完整故事起伏不同。
- `concepts/structure#35` **过程记录**：需要能拆步骤并展示的真实行动、过程中的期待与结果。原页面向实拍；用于文章/口播时只能借“追过程材料”，标明迁移，不声称原方法天然适配所有形式。
- `concepts/structure#44` **对比测评**：需要可重复测法、固定条件、真实结果。外部评测可作转述；没有自己测过不能交“我实测”的推荐。

其他如讲别人怎么做成、回应偏见、关系小事、体验与追根溯源，按速查页选择并回读。本导航未收录不代表不适合。娱乐、陪伴、审美与日常记录按其观看体验采集，不能只拿“证明观点/教会方法”验收。

## 日常积累与主动采集

- **四类素材库**：`methods/method_principle/method-e38cb67ccfd54d6c`。按选题、开篇、金句、呈现区分用途；每次收藏加一句为什么存。这是表达素材的分类，不替代本次研究的事实材料卡。需要平台搜法回读 `sources/course/xuehui-4d9fba18b76c9d41`。
- **收藏观点素材提升敏锐度**：`methods/method_principle/method-f7743880ddd5534a`。积累观点及其论据与反对意见，识别谈话中的判断；不能只攒漂亮金句。
- **提前准备知识点或论点**：`methods/method_principle/method-7da1d6dc212eba53`。原场景是自然流访谈；迁移为采访/调研前的问题准备。三个是原课建议，不是所有选题的强制数量。
- **观察真实工作状态**：`methods/method_principle/method-f6dd5c82231627ad`。原场景是老板 IP 拍摄；有实地权限时观察工作与交往中的具体动作。其他人物题材是本 Skill 的迁移用法，不假称已去现场。

## 覆盖记录

日常任务只记录对本题有意义的候选。字段：方法原名、出处、采用/待补/不适合、对应问题、实际采集动作、材料编号、未解决缺口。覆盖验收时再扩大候选范围，逐项说明，不要求每题使用所有方法。

“原方法怎么写”保留在完整快照或实时 Wiki 中；“这次怎么迁移、没有沿用什么”写在任务记录中，不修改原快照内容。
