判断选题缺哪些材料，搜集原话、案例、过程和细节，整理成保留出处的素材包。

本仓库包含完整技能入口及所需的本地脚本和参考文件。使用流程从 [SKILL.md](SKILL.md) 开始。

## 获取与使用

```bash
git clone https://github.com/guasi18587278913/topic-material-research.git
```

仓库根目录就是技能目录。将整个目录放入所用客户端的技能目录；保留目录结构，不只复制 SKILL.md。已有同名技能时，先检查本地修改再合并。

调用示例：`用 topic-material-research，根据我提供的材料完成素材调研搭档任务。`
